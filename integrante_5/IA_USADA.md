# Reporte de Uso de Inteligencia Artificial (Gemini)

Para la resolución de las Actividades 1, 2, 5, 6 y 7, se utilizó la herramienta Google Gemini. A continuación, se detallan los prompts (instrucciones) utilizados:

## Prompt 1: Generación de códigos QR y Barras (Tarea 1)
> "Buenos dias gemini, el dia de hoy te mandare ciertas tareas para la materia de programacion movil 2... Tarea 1: Generador HTML de Códigos QR y Códigos de Barras Imprimibles (Actividad 2). Objetivo: Crear una página web simple y local que permita imprimir en papel los códigos QR y de barras de prueba exigidos para el reto (PRD001, PRD002, PRD003). Requisitos: Usar librerías CDN, generar tarjetas limpias con QR y Code 128, incluir estilos CSS para impresión (@media print)."

## Prompt 2: Script de Concurrencia (Tarea 2)
> "Tarea 2: Script de Prueba de Concurrencia y Bloqueo Pesimista (Caso P10 / Actividad 7). Objetivo: Simular en la terminal dos peticiones POST simultáneas enviadas a movimientos.php para demostrar que el bloqueo SELECT ... FOR UPDATE de MySQL solo aprueba una y rechaza la otra. Actúa como Ingeniero de QA. Necesito un script de PowerShell que envíe DOS peticiones HTTP POST SIMULTÁNEAS al mismo milisegundo."

## Prompt 3: Bitácora de Defectos (Tarea 3)
> "Tarea 3: Plantilla de Registro y Control de Defectos P01-P11 (Actividades 1, 5 y 6). Objetivo: Llevar la bitácora de ejecución en vivo. Actúa como Líder de QA. Genera una tabla en formato Markdown para registrar la ejecución en vivo de los 11 casos de prueba del proyecto Inventario QR (P01 al P11) con las columnas correspondientes."

## Prompt 4: Estructura de GitHub
> "Necesito subir a github mira uno de mi equipo subio eso, la verdad no se que tengo que subir [Adjuntando imagen de la estructura del repositorio]".
